Why HIAI

Built for focused, safe development.

Security model

Local-first

Your code and project context stay on your machine. HIAI never requires a cloud-hosted project workspace.

OpenRouter models

Use free or paid language models through OpenRouter while keeping model selection flexible and configurable.

Natural-language control

Ask for changes, explanations, searches, or test runs in plain language instead of memorizing a complex interface.

Approval-based actions

File writes and development commands require confirmation by default, with dangerous operations blocked outright.

Web research

Search documentation and current technical references with the optional Tavily search provider.

Standard library only

The runtime depends solely on Python's standard library, making installation and maintenance straightforward.

Architecture

One CLI. A modular Python core.

HIAI combines the agent loop, OpenRouter client, search integration, permissions, and file tools in a compact Python package.

Quick start

Run HIAI in minutes.

Install from source, configure a model, and start a project conversation.

Install from source

git clone https://github.com/toewaioo/hiai.git
cd hiai
python -m venv .venv
source .venv/bin/activate
pip install -e .

Start an agent session

hiai
hiai --project ./my-project "Create the requested changes"

Configure a model

hiai config set-key
hiai config set-model openrouter/free

Test the project

make test
make lint
make clean

Safety

Designed to protect your workspace.

Security controls are built into the CLI workflow rather than left to user habit.

Sandboxed file operationsFile access is restricted to the active project root.
Path traversal blockedAttempts to escape the workspace are rejected.
Commands need approvalDevelopment commands run only after user confirmation.
Writes are confirmableFile creation and replacement are safe by default.
Dangerous actions blockedSystem-level destructive commands are always rejected.
Secrets stay protectedAPI keys are not printed or sent to the AI model.
